PC 통합 정보 확인 도구
PC 통합 정보 확인 도구는 Windows 및 Windows PE 환경에서 PC의 식별 정보, 주요 부품, 네트워크 설정과 온도 센서를 한 번에 확인할 수 있도록 제작된 프로그램입니다.
삼성, Dell, HP 등 완제품 PC와 조립 PC를 지원하며 데스크톱과 노트북에서 사용할 수 있습니다. 복잡한 명령어 없이 화면에서 필요한 정보를 조회하고 저장할 수 있어 PC 입출고 관리, 자산 조사, 유지보수 및 장애 점검 작업에 활용할 수 있습니다.
주요 기능은 다음과 같습니다.
PC 모델명, 제조번호, UUID 등 식별 정보 조회
Windows 및 Windows PE 환경 감지
OS 버전과 빌드 정보 확인
CPU 모델, 코어·스레드 및 최대 클럭 확인
메인보드와 BIOS 정보 확인
메모리 슬롯별 모델, 용량, 속도 및 시리얼 조회
그래픽카드와 드라이버 정보 확인
HDD, SSD, NVMe의 모델, 시리얼, 용량, 펌웨어 조회
CPU, GPU, 저장장치, 메인보드 온도 확인
정상·경고·초과 상태를 색상으로 구분
네트워크 연결 상태 및 자동 DHCP·수동 고정 IP 구분
IP 주소, 서브넷, 게이트웨이, DNS, DHCP 서버, MAC 주소 조회
조회 결과 복사 및 CSV 저장
저장된 정보 파일 열기
장치관리자, 네트워크 설정 및 디스크 관리 바로 실행
온도 정보는 LibreHardwareMonitor를 기반으로 조회하며, 지원되지 않는 환경에서는 WMI, ACPI 및 NVIDIA-SMI 방식으로 자동 전환됩니다. 일부 센서는 PC 제조사, 부품 모델, 드라이버 및 관리자 권한에 따라 표시되지 않을 수 있습니다.
이 프로그램은 다양한 PC의 정보를 빠르고 일관된 방식으로 수집해야 하는 전산 담당자와 유지보수 작업자를 위한 통합 점검 도구입니다.
